Find the dependencies nobody maintains anymore

npm audit lists known vulnerabilities. It does not tell you which of your packages are deprecated, archived or kept alive by a single person. oss-health-scan does, in your terminal and in CI.

npx oss-health-scan
View on GitHub View on npm

What it checks

It ships as a command-line tool and as a GitHub Action, with no runtime dependencies of its own.

  • Scores every dependency from 0 to 100.
  • Flags packages that are deprecated, archived or unmaintained.
  • Checks known vulnerabilities against OSV.dev.
  • Comments on pull requests and can fail the build on critical findings.
  • Writes SARIF for GitHub Code Scanning and a stable JSON manifest for audits.

State of npm Abandonment 2026

I scanned 123 of the most-depended-on npm packages. 20 of them are deprecated or archived, and together they still account for about 297 million downloads a week.

Each square is one scanned package. Amber squares are deprecated or archived.
